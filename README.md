# Hospital-Information-Management-Analytics
A PostgreSQL-based hospital information management and analytics project using SQL for patient, doctor, appointment, revenue, and performance analysis.

Hospital Information Management & Analytics System

📌 Project Overview

A PostgreSQL SQL project created to manage and analyze hospital data.

The project covers patients, doctors, appointments, admissions, medicines, payments, and revenue.

🔍 Key Analysis

- Monthly and running revenue
- Month-over-month revenue change
- Top patients by medical spending
- Doctor performance and revenue
- Patients from the same city
- Duplicate patients
- Oldest patient
- Expired medicines
- Unpaid bills
- Appointment analysis

🧠 SQL Concepts Used

- SELECT, WHERE
- GROUP BY & HAVING
- JOINs
- Subqueries
- CTEs
- Window Functions
- DATE_TRUNC
- Views
- Indexes
- EXPLAIN ANALYZE

PostgreSQL | pgAdmin | SQL | GitHub
